# Dataset Source and Attribution

## Dataset
Brazilian E-Commerce Public Dataset by Olist

## Source
- Provider: Olist
- Platform: Kaggle
- Original dataset: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- Data period: 2016–2018
- Format: CSV
- Files: 9

## Description
The dataset contains anonymised commercial data from approximately 100,000 orders placed through the Olist e-commerce platform in Brazil. It includes information about orders, customers, products, sellers, payments, reviews, and geolocation.
