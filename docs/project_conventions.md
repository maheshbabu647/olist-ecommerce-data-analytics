
# Project Conventions

- Preserve original CSV files in data/raw/.
- Never overwrite raw source data.
- Store reproducible transformations in code.
- Use descriptive file and variable names.
- Keep SQL scripts organised by purpose.
- Use Python notebooks for exploratory work.
- Record assumptions and data-quality decisions.
- Validate important findings independently.
- Do not commit raw or processed datasets to GitHub.
- Every reported finding must be reproducible.
