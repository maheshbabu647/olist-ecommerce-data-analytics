
# Olist E-Commerce Data Analytics

## Project Overview

An end-to-end data analytics investigation of the Brazilian E-Commerce Public Dataset by Olist, containing approximately 100,000 orders from 2016–2018.

The objective is to investigate business performance and identify evidence-based insights across sales, customers, products, sellers, payments, logistics, and customer satisfaction.

## Business Objectives

- Evaluate overall order and business performance.
- Understand customer purchasing behaviour.
- Identify high-performing products, categories, and sellers.
- Analyse payment patterns.
- Evaluate delivery performance and customer satisfaction.
- Translate findings into actionable business recommendations.

## Dataset

Source: [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Provider: Olist

Period: 2016–2018

Files: 9 CSV datasets

License: CC BY-NC-SA 4.0

The original dataset is anonymised. Raw data is not included in this repository.

## Technology Stack

- Python — Data profiling, exploration and statistical analysis
- PostgreSQL — Relational database and SQL analysis
- Excel — Data inspection and validation
- Power Query — Data transformation
- Power BI — Interactive dashboards and reporting

## Project Workflow

1. Project setup and source inventory
2. Structural and statistical data profiling
3. Data-quality investigation
4. Relational database design
5. PostgreSQL implementation and validation
6. Business questions and metric definitions
7. Business performance analysis
8. Product and seller analysis
9. Customer and payment analysis
10. Logistics and satisfaction analysis
11. Advanced analysis and Power BI
12. Reporting and publication

## Reproducibility

1. Clone this repository.
2. Download the original dataset from Kaggle.
3. Extract all nine CSV files into `data/raw/`.
4. Follow the project notebooks and SQL scripts.

Raw and processed datasets are excluded from Git tracking.
